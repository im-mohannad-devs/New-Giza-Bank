## Overview

**New Giza Bank** is a front-end banking management prototype built to demonstrate modern web development, interactive UI design, client-side state management, and role-based user experiences.

The project provides separate customer and administrator interfaces, allowing users to explore a simulated banking environment through a clean, interactive web application.

## Features

- **Customer Portal** — A dedicated interface for customer-facing banking features.
- **Admin Portal** — A separate administrator experience.
- **Login Interface** — Interactive authentication screens for demo users.
- **Light & Dark Mode** — Theme switching with consistent visual styling.
- **Smooth Animations** — Transitions and interactive UI elements for a polished experience.
- **Interactive Components** — Forms, modals, buttons, and user actions.
- **Client-Side Data Storage** — Browser-based state and demo data persistence using `localStorage`.
- **Modular JavaScript** — Separated application logic, views, shared utilities, and event handlers.

## Getting Started

### Prerequisites

- A modern web browser.
- Git, if you want to clone the repository.
- Visual Studio Code (recommended for development).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/im-mohannad-devs/New-Giza-Bank.git
```

**2. Open the project**

```bash
cd New-Giza-Bank
```

**3. Run the application**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for local development.

No package installation or build step is required.

## Security & Limitations

New Giza Bank is an educational front-end prototype.

- Authentication is simulated on the client side.
- Demo data is stored in browser storage.
- There is no production banking backend or secure server-side authentication.
- Do not enter real banking credentials, personal information, or financial data.

A production banking application would require a secure backend, a database, server-side authorization, proper session management, and additional security controls.
