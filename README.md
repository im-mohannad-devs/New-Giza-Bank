# New Giza Bank

Open `index.html` in a browser. No build step.

- `css/style.css`  themes (light/dark tokens), layout, animations
- `js/core.js`     helpers, seed data, localStorage store, shared state
- `js/views.js`    login screen, app shell, all pages
- `js/actions.js`  clicks, forms, modals, business rules
- `js/main.js`     theme boot and first render

Demo: sara@newgiza.bank / demo123 (customer), admin@newgiza.bank / admin123 (admin).
Front-end prototype only: data lives in the browser.
